## 🚀 Deployment Steps

```bash
# 1. Deploy SQL Schema (5 minutes)
npx @insforge/cli db query "$(cat insforge/tables-critical.sql)"
npx @insforge/cli db query "$(cat insforge/rls-policies.sql)"

# 2. Verify Deployment (1 minute)
npx @insforge/cli db query "SELECT tablename FROM pg_tables WHERE schemaname='public';"

# 3. Build Frontend (10 seconds)
npm run build

# 4. Test Integration
npm run dev
# Go to /login and test password reset
```
